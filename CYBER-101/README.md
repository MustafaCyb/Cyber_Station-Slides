# CYBER-101

This is the introductory Cyber Station lecture. It gives students a broad foundation in cybersecurity, starting from basic concepts and moving through operating systems, command-line usage, programming, networking, offensive security, defensive security, malware analysis, forensics, reverse engineering, and AI in cybersecurity.

## Materials

- `CYBER-101.pdf` - full introductory lecture slides.

## Main Topics

- Cybersecurity basics, the CIA triad, and core terms such as asset, vulnerability, threat, risk, and exploit.
- Common myths about cybersecurity and why theory, programming, and updates matter.
- Computer basics including binary, hexadecimal, CPU, registers, RAM, processes, threads, and privilege rings.
- Windows, Linux, macOS, file systems, permissions, and command-line fundamentals.
- Bash scripting, C++ basics, Python basics, and a simple Python port scanner.
- Networking fundamentals, ARP, common network attacks, IDS/IPS, VPNs, firewalls, and SIEM.
- Offensive security fields such as network testing, Wi-Fi testing, web security, system hacking, OSINT, and social engineering.
- Defensive security fields such as SOC, incident response, threat hunting, EDR, SIEM, digital forensics, reverse engineering, and malware analysis.
- Future trends, including defensive AI, offensive AI, and attacks against AI systems.

## Lecture Goal

The goal is to give beginners a clear map of the cybersecurity field and the technical foundations needed before choosing a deeper path.
