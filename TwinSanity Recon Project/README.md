# TwinSanity Recon Project

This lecture introduces TwinSanity Recon, an AI-powered web reconnaissance and vulnerability assessment platform for security professionals, bug bounty hunters, penetration testers, and teams managing large external attack surfaces.

## Materials

- `TwinSanity-Recon.pdf` - lecture slides.

## Main Topics

- Passive subdomain enumeration from sources such as crt.sh, SecurityTrails, VirusTotal, Chaos, HackerTarget, and AlienVault OTX.
- DNS resolution, HTTP probing, technology fingerprinting, port scanning, CVE lookup, URL harvesting, and API discovery.
- AI-powered analysis using multiple LLM providers and local Ollama models.
- Web dashboard features including live scan updates, Shodan integration, CVE Explorer, admin panel, AI chat, light/dark mode, and report generation.
- Architecture based on Python 3.10+, Flask, WebSocket updates, YAML configuration, modular scanning components, and NVD API integration.
- Output workflows including executive summaries, technical reports, severity breakdowns, NIST/NVD references, PDF export, and public scan sharing.

## Lecture Goal

The goal is to show how reconnaissance, vulnerability enrichment, and AI-assisted reporting can be combined into a single workflow for authorized security assessment.
