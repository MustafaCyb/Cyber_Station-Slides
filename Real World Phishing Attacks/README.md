# Real World Phishing Attacks

This folder covers social engineering, OSINT-driven attack-surface mapping, and a dynamic phishing lab. The material explains how attackers gather public information, build a strategy, deliver phishing content, and how defenders can reduce the risk.

## Materials

- `Mapping and Exploiting Social Networks as Cybersecurity Attack Surfaces.pdf` - main lecture slides.
- `LAB.pdf` - dynamic phishing lab slides.
- `Microsoft365.yaml` - phishlet-style YAML material used with the lab.

## Main Topics

- OSINT information gathering from social media, DNS/WHOIS, search engines, leaked databases, and public infrastructure.
- Tools and platforms such as Maltego, SpiderFoot, Shodan, GoPhish, Evilginx, and TwinSanity Recon.
- Attack stages: information gathering, strategy development, weaponization and delivery, execution and impact, and mitigations.
- Static phishing, dynamic phishing, adversary-in-the-middle attacks, malware delivery, and real-world case studies.
- Evilginx concepts such as phishlets, lures, sessions, reverse proxy behavior, and captured session data in a controlled lab context.
- Defensive controls including SPF, DKIM, DMARC, phishing-resistant MFA, secure email gateways, EDR, domain/certificate monitoring, backups, and user training.

## Lecture Goal

The goal is to show how social engineering attacks become more effective when they are based on reconnaissance, and to connect each attack stage to practical defensive controls. Any lab material should be used only in an authorized classroom or test environment.
